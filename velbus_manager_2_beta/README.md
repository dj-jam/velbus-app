# Velbus Manager 2.0 Beta

Velbus Manager 2.0 for Home Assistant OS, controlled through an admin-only
Ingress panel. No host port, broad Supervisor access or unrestricted USB access
is enabled. Runtime data is persisted in `/data`.

The app is experimental. Start with a simulator before connecting a physical
Velbus gateway. Installing this app does not install the Velbus integration in
Home Assistant Core.
